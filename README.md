# GoldenAura Browser Play Guide

Public reference for playing GoldenAura casino titles directly in a mobile browser — no large app download — plus per-game guides and a per-provider RTP index compiled from in-game help screens.

- Play: https://goldenaura.cloud/
- Library: https://goldenaura.cloud/games/
- Promotions: https://goldenaura.cloud/page/promotions
- VIP: https://goldenaura.cloud/page/vip

## What is in this repo

- `games/` — 827 game guides across 41 providers (`<Provider>/<Slug>/README.md`). Each guide covers how to open and play the title in a browser, its paytable features, and where to check RTP in-game, with a direct play link `https://goldenaura.cloud/games/[Slug]/`.
- `provider-rtp-tables/` — one RTP index per provider, rolled up from the game guides.
- `promotions-and-bonus-guides/` — welcome pack, cashback, rakeback, races, wheel, lottery, referrals.
- `vip-system-docs/` — Bronze to SVIP/High-Roller, manager, birthdays.
- `categories-guides/` — slots, hot, jackpots, full library.
- `browser-play-performance/` — instant-play vs app, storage check anyone can reproduce in DevTools.
- `payment-and-cashier-docs/` — deposits, withdrawals, crypto, KYC.
- `fairness-and-responsible-play/` — RNG/fairness, 18+ responsible play, terms.
