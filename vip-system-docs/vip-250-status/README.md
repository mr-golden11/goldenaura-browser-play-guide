## What the status means

- Rank 0–29: regular player climbing to VIP. Bar shows percent to Rank 30.
- Rank 30+: `VIP Unlocked` — personal bonuses, Welcome Bonus, birthday treat, priority withdrawals.
- Rank 57+: `Super VIP Unlocked` — SVIP lounge, SVIP bonus, Diamond Wheel up to $500K.
- Rates scale: cashback 3% (Rank 0–17) to 40% (Rank 77), rakeback to 15% max.
