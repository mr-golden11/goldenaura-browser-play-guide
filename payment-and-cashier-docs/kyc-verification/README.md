# KYC Verification — One-Time ID Check (GoldenAura)

KYC is a one-time identity check that confirms you are 18+, prevents fraud, and unlocks withdrawals. Deposits and play can come first; payouts stay pending until KYC is approved.

All uploads happen only inside your logged-in account area. Never send ID photos over email, chat, or Telegram.

## KYC steps (ID + proof, one-time)

1. Log in at https://goldenaura.cloud/ and open Profile → Verification / KYC. Check which level is requested: email, identity, or address.
2. Confirm email (and phone if requested) via the link / code sent to you.
3. Upload photo ID proving 18+: passport, national ID card, or driving licence showing photo, full name, date of birth, and expiry. All four corners visible, no glare, JPG/PNG.
4. Upload proof of address: utility bill or bank statement from the last 3 months showing full name + address matching your account exactly.
5. Wait for review (usually under 24 hours). You can continue playing while waiting — e.g. Sweet Bonanza, Wolf Gold via https://goldenaura.cloud/games/. Re-check status in Profile, then request payout at https://goldenaura.cloud/cashier.

## If verification fails

- Blurry / cropped ID → re-take in daylight, include all corners.
- Old bill or name mismatch → upload a recent document with exact account name and address, or ask support to fix a registration typo first.
- Withdrawal blocked → finish ID + address steps, clear any active bonus wagering, then re-request. Minimum withdrawal is $10 (illustrative — confirm live cashier).
