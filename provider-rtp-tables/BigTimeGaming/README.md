## How to Check RTP on GoldenAura

1. Open the library: https://goldenaura.cloud/games/
2. Launch the BTG title and open **Help / Paytable / Rules**.
3. Look for **Return to Player / RTP / Theoretical Return** — check for ranges, Megaways ways-count notes, and mode-dependent values (e.g. base game vs. bonus buy / feature spins where offered).
4. Review ways, cascade / multiplier rules, stake range, and session limits in the same panel. High-volatility Megaways-style games can feel sharp — set time and budget limits first. If no figure is shown, treat it as unconfirmed for that version.
