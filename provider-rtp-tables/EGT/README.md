# EGT — RTP Table

Provider: EGT | Games indexed: 127 | Hub: GoldenAura `provider-rtp-tables/EGT/`

EGT (Euro Games Technology) is the classic land-based-rooted studio behind many fruit, dice, and jackpot-style video slots, including Burning Hot, Shining Crown, and the large 40-line family. This page is the GoldenAura RTP index for the 127 EGT titles currently documented under `games describtion readme files/EGT/`. It is also the canonical table for Amusnet, which as successor to EGT shares that catalogue without duplicating rows. Each EGT game folder has its own educational README, and this hub consolidates them into one table.

EGT return figures differ by version, market, and configuration, so every game README in this batch keeps return generic and points to in-game help for the official number on the opened version. The RTP column below is therefore parsed verbatim as `in-game help` for all rows, with no fixed percentages claimed here. Source likewise reads `in-game help`, and Play links each slug to `https://goldenaura.cloud/games/[Slug]/` for browser play.

To use the table, locate a game, copy its slug exactly, then follow the Play link and open the help panel to confirm lines, features, and return for your session. This is a docs-only index with no backend. RTP describes long-term theory across many rounds. Check official rules in-game, keep stakes modest, and play responsibly. Adults 18+ only.
