## How to Check RTP on GoldenAura

1. Open the library: https://goldenaura.cloud/games/
2. Launch the Skywind title and open **Help / Paytable / Rules** (usually `i`, `?`, or menu icon).
3. Look for **Return to Player / RTP / Theoretical Return** — check for ranges or mode-dependent values (e.g. base game vs. bonus buy / jackpot side bet where applicable).
4. Confirm stake limits, feature rules, and game history in the same panel before playing. If no figure is shown, treat it as unconfirmed for that version.

For live-table formats, check the table rules screen instead: payouts, side bets, and deck / wheel configuration determine the return — there is no single slots-style RTP number.
