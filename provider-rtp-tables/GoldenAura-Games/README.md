# GoldenAura-Games RTP Guide at GoldenAura

GoldenAura-Games is used here as a platform-level label for GoldenAura's own curated browser-play collection, rather than a single third-party studio.

This RTP hub is an overview only. No per-game RTP rows are listed under this label because gold-themed titles found in the games source (for example GoldenHornsBS or GoldenGrimoireNET) belong to their suffixed providers and are not counted as GoldenAura-Games originals. No RTP percentages are invented here — refer to each game's own help screen for certified values.

How to use RTP in this collection:

- RTP describes long-term theoretical return across many plays; short sessions vary widely.
- Open the paytable and game rules in the lobby version to confirm RTP, reels, lines, and feature triggers.
- Use volatility as context: matching RTP with low, medium, or high volatility helps set session expectations.
- Browse by theme and mechanics first, then confirm math details in-game before staking.
