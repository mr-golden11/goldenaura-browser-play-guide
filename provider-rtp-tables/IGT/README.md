## How to check RTP when IGT titles appear

1. Open the game from https://goldenaura.cloud/games/ when live.
2. Wait for full load, then open `Paytable`, `Help`, `Game Rules` or `?`.
3. Look for `RTP` / `Theoretical Return`.
4. Note paytable and bet-way details — IGT adaptations often document them on the same screen.
5. Trust only the figure inside that exact game window.

## RTP and volatility in plain terms
