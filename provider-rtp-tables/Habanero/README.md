## How to check RTP when Habanero titles appear

1. Open the game from https://goldenaura.cloud/games/ when live.
2. Wait for full load, then open `Help`, `Paytable`, `Settings` or `?`.
3. Find `RTP` / `Theoretical RTP` and any volatility label on the same panel.
4. Check bet-size and payline notes — they sit next to the RTP on most Habanero help screens.
5. Use only the in-game figure as the reference for that session.

## RTP and volatility in plain terms

RTP is theory over thousands of rounds, not ten minutes. Low volatility means steadier small results; high means quieter stretches with sharper peaks. Because editions can differ, always read the figure printed in the game help panel.
