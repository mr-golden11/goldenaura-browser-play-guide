## How to check RTP for any Play'n GO title on GoldenAura

1. Open the game link from the table.
2. Wait for art and balance to load.
3. Open `?`, `i`, `Menu`, `Paytable`, `Help` or `Game Rules` (label varies by title).
4. Look for `RTP`, `Theoretical Return` or `Return to Player`.
5. Note the exact figure for *that* session — table games (Casino Holdem, Super Wheel), bingo (Sweet Alchemy Bingo) and grid slots (Troll Hunters 2) label it differently.
6. If you do not see a figure, treat third-party lists as background only; the in-game panel wins.

## RTP and volatility in plain terms

RTP is a long-run average across many rounds, not a promise for one session. Volatility describes feel — low means smaller steadier results, high means rarer sharper swings. Play'n GO titles span low to high volatility, so read the in-game help for both numbers and use them only as context with time and spend limits.
