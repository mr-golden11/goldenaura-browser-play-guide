## RTP and volatility in plain terms

RTP is a long-run average across many rounds, not a promise for one evening. Volatility describes feel — low means smaller steadier results, high means rarer sharper swings. Because editions can differ, always read the figure printed in the game help panel and use it only as background context with time and spend limits.
