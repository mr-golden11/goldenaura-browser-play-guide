## How to play

1. **Choose your stake:** Set totals from $0.10 to $100.00. All ten lines stay fixed.
2. **Spin the mine:** Press spin. Miner matches on a line from the left pay.
3. **Blast the dynamite:** Dynamite wilds transform neighbours into wild completions.
4. **Chase the top:** Blasted sequences build toward the 10,000-coin top.
5. **Check paytable:** confirm stakes, line values and rules in-game, as settings vary.
