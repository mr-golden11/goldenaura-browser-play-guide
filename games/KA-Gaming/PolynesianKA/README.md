# Polynesian

Provider: KA Gaming

Polynesian (PolynesianKA) by KA Gaming is a Polynesian moai-collection theme presented as a browser video slot. It runs on desktop and mobile without downloads: open the entry, read the help screens, set the stake, then spin. Touch controls and autoplay where offered keep short sessions simple.

In the local game source, the paytable states: WILD substitutes for all symbols.; Any wins with WILD substitution in FREE GAMES reward a random multiplier of 2x to 5x. That is the behaviour to verify on the help pages before raising the bet, since free-game counts, retrigger limits and multipliers differ across the KA catalogue.

How to open it: visit the GoldenAura library, search for PolynesianKA, then select the entry. This page keeps return-to-player generic: no RTP figure is printed in the local source files examined, so check the in-game help for the official RTP of your version. RTP describes long-term theory across many rounds, not a single session. Newcomers should start small, observe how wilds and scatters behave, and keep session time and budget limits.
