Picture a friendly sushi counter with salmon, tuna, wasabi and wooden-plate presentation. Each round resolves alone, so it is easy to play slowly and stop anytime.

## Playing in your browser

Tap the game link, allow a few seconds to load, and adjust stake with plus and minus. Close background tabs if graphics stutter.

## RTP and volatility in plain terms

RTP is the long-run share a game is designed to return over many rounds; volatility is how bumpy it feels. Exact figures vary by version, so check the in-game help for this release and treat it as context, not a promise.

## Launch steps
