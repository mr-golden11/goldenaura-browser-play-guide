## What to expect

Expect a northern sea saga with longships, runes, ravens and storm-grey seascapes. Rounds are short: set a stake, start the round, and read the result before continuing.

## Playing in your browser

You play in the browser window. Open the link below, wait for the bar to finish, then use on-screen buttons. On mobile, landscape helps if buttons feel cramped.

## RTP and volatility in plain terms

RTP is the long-run share a game is designed to return over many rounds; volatility is how bumpy it feels. Exact figures vary by version, so check the in-game help for this release and treat it as context, not a promise.
