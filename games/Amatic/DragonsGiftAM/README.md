## Paytable
"- Payouts according to the paytable are made only if the specified number of symbols is of a kind."
- The Wild symbol substitutes every other symbol except the Bonus symbol.
- The Wild symbol appears only on reel 2, 3 and 4.

## Free Games and Gamble

- Bonusspins are played at the same bet and number of lines as the initiating game.
"- With active gamble mode the player has the chance to multiply the win; double by color, quadruple by suit."
