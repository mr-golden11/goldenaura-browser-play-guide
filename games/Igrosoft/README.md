# Igrosoft — Provider Hub on GoldenAura

Igrosoft is a veteran studio with roots in 1990s land-based video slots, later widely recognised online for simple, nostalgia-driven reel games. Its classic style generally means five-reel layouts with fixed paylines, basic wild and scatter roles, and understated bonus games such as double-up gamble rounds and small pick features, without complex cascading systems.

If you are new to this provider, the most useful concepts to learn first are paytable structure, fixed-line betting, how gamble and double-up features affect variance, and how scatter-triggered bonus screens and multipliers interact. Guides in this folder explain those mechanics using live GoldenAura titles as examples.
